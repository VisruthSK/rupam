# Related work

- Hindley–Milner with row polymorphism; Morris and McKinna, extensible data types.
- Coeffects (Petricek, Orchard and Mycroft) for contextual requirements; PRIMUS.
- Liquid types and occurrence typing for refinements.
- Futhark size types for symbolic sizes.
- B2T2 for table-type expressiveness; PingPong for keyed lookups.
- dplyr and Polars as the target semantics compared in conformance.
